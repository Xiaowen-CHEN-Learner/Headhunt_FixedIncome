# Validation record

## Offline bond example — 2026-10-03

Environment: Python 3.13.5, Linux. No third-party Python packages, network requests, credentials, or source workbooks are required by the example.

Commands actually executed:

```bash
python bond_demo.py --output examples/expected_scenarios.csv
python -m unittest discover -s tests -v
```

Result: **15 tests passed**. This is a local test result, not a claim that GitHub Actions has run.

The suite checks par and zero-coupon identities, zero and negative yields, monotonicity, face-value scaling, zero-coupon duration, finite-difference duration/convexity, invalid inputs, and deterministic CSV reproduction. The expected CSV was generated by this implementation; it is a regression fixture, not independent market validation. The pricing identities and finite-difference checks provide separate internal consistency checks.

The example assumes coupon-date settlement, whole coupon periods, fixed coupons, and one flat nominal annual yield compounded at the coupon frequency. It does not implement day-count conventions, accrued interest, calls, defaults, curve bootstrapping, transaction costs, or issuer credit analysis.

The October 1 data exports have **not** been validated by these tests. This example does not read or republish them. Their sources, observations, and redistribution conditions require a separate review.

Implementation and tests were prepared with AI assistance during a portfolio improvement session. They are an educational baseline for Xavier to study, review, and extend, not evidence of an independently built production platform.
